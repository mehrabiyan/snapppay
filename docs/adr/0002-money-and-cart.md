# ADR 0002 — Exact integer rials and invoice balance allocation

Accepted 2026-10-05. Parse decimal currency strings exactly into integer rials; IRR scale=1, IRT/TMN scale=10. Reject nonintegral rial precision and overflow. WHMCS gateway amount is remaining invoice balance. Credits, previous payments, tax and discounts complicate original unit prices. Preserve positive invoice-item identities and distribute payable balance proportionally with deterministic largest-remainder allocation. Provider lines are payable tax-inclusive amounts, count=1; included-tax flag true. ExternalSourceAmount/discountAmount zero because adjustments already reflected in net lines. Report proportional included tax, sum cart exactly equals requested amount. Refund reductions use saved identities, proportionally lower amounts, remove exhausted lines and retain total invariant. UI explains allocation; item-specific commercial refund selection is separate from WHMCS's amount-only native refund contract. Require merchant demo confirmation; reject unrepresentable empty positive cart.
