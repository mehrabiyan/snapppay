# ADR 0003 — Callback is untrusted; provider status authorizes payment

Accepted 2026-10-05. Public callback has no documented signature. Correlate saved high-entropy alphanumeric transaction ID, exact callback amount, then obtain authenticated provider status and match ID/amount. Never trust callback state as settlement proof. Write verify intent before send, query status before retry, bound retry count; SETTLE alone permits ledger posting. Reconcile cron handles abandoned browser and crash windows. FAILED callback cannot cause automatic revert from attacker input. Revert requires operator confirmation and provider enablement. Cross-tab payments serialized by invoice lock; settled second payment on already-paid invoice requires review rather than duplicate credit. Secrets encrypted using WHMCS encrypt/decrypt; no persistent OAuth cache. Record merchant endpoint fingerprint to prevent cross-environment recovery.
