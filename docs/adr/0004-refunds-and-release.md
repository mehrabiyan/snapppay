# ADR 0004 — Native refund accounting and honest release gates

Accepted 2026-10-05. Full refund=cancel, partial refund=update with persisted reduced snapshot. Only WHMCS authenticated administrator refund call may mutate; addon directs user to native Refund tab and previews allocation. Persist refund intent before provider call. Recover uncertain cancel from CANCEL and partial update from SETTLE with exact target amount. Return stable refund transaction ID to WHMCS once. Persist handed_off flag before returning; overlapping/replayed native requests stop while accounting is absent. Recovery after handoff/core crash requires operator accounting repair, preventing duplicate WHMCS refund records. Require recorded WHMCS refund before allowing another operation; provider success/core-accounting crash surfaces explicit repair gate. Never auto-cancel settled purchases on invoice hooks. Local simulator proves wiring and service behavior; licensed WHMCS and provider stage acceptance remain external gates. Production configuration requires explicit certification acknowledgment, configured endpoint/redirect host, HTTPS and whitelists. Ship deterministic ZIP, checksums, install/runbook, security/test report; never fabricate live certification.
